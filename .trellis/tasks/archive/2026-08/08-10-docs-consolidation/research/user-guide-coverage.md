# 用户指南覆盖清单

本清单只用于验证 `docs/user-guide.md` 的功能覆盖，不作为新的产品事实源。功能语义和验收仍以 `docs/requirements.md` 为准。

## 功能面

每项至少说明：解决的问题、页面或入口、主要操作、用户得到的结果、关键限制或需要审批的边界。

- [x] Workspace 连接、激活、切换与隔离。
- [x] Inbox 与 Quick Capture：文字、URL、文件、图片等资料进入系统。
- [x] 内容解析、标准化、版本和来源追踪。
- [x] 关键词、语义和混合搜索，以及证据定位。
- [x] 新建文档、材料整理、文章优化、版本比较与文件历史。
- [x] Topic、Claim、Relation 和 Conflict 的知识抽取与判断。
- [x] Proposal 的创建、查看、修改建议与 Diff。
- [x] Approval 的批准、驳回和风险检查。
- [x] 安全写回、Git 提交、重新索引、冲突与恢复。
- [x] 带引用的 RAG 对话、澄清、拒答和反馈。
- [x] Artifact：大纲、专题文章、面试资料和学习路径等产物。
- [x] 全局、局部和路径知识图谱及证据详情。
- [x] 语义候选关联的发现、确认和拒绝。
- [x] Smart Collection 的筛选、视图和导出。
- [x] 知识健康问题的发现、决策和修复建议。
- [x] 知识时间线、影响分析和下游更新建议。
- [x] Memory 的候选、确认、管理和作用范围。
- [x] Review、闪卡、FSRS 调度、评分与知识缺口修复。
- [x] Interview 模拟、追问、结果与后续学习路径。
- [x] Workflow/任务中心的状态、暂停、恢复、取消和失败处理。
- [x] Agent 工具调用的可见性、权限和“不能直接写入”的限制。
- [x] Dashboard、通知、审计、模型/成本等用户可见状态。
- [x] Settings、模型配置、Git 同步、维护与导出。
- [x] Document/Topic/Claim 等知识对象的新建、移动、合并、归档和删除边界。
- [x] Conflict 的调查、选择、接受分歧和综合处理。

## 端到端流程

- [x] 首次连接 Workspace 到进入工作台。
- [x] 导入资料到检索可用。
- [x] 资料分析到 Proposal、审批、安全写回和重新索引。
- [x] 搜索或提问到查看引用、冲突和反馈。
- [x] 从知识生成 Artifact 到审阅或发布。
- [x] 从图谱/健康/时间线发现问题到形成修复建议。
- [x] 从知识生成 Review/Interview 到更新学习计划。
- [x] 失败、刷新、重启、版本冲突或外部修改后的恢复方式。

## 可读性边界

- [x] 不要求用户理解 Go、PostgreSQL、pgvector、River、Eino、Schema 或内部 Adapter。
- [x] 不复制 OpenAPI、数据库字段、内部状态表和测试门禁。
- [x] 对尚未交付或需要额外配置的能力明确标记，不把目标需求描述成当前可用。
- [x] 使用稳定产品术语，并在首次出现时用普通语言解释。
