# 首页确认稿视觉拆解

## 分析范围

本任务已有一轮完整的 image-first 探索，用户最终确认 `2：Minimal map`，并明确否决知识星座增强稿。因此开发不再生成竞争方案，而把以下四张独立效果图作为视觉源：

- `workbench-map-b-minimal.png`：未连接态，`1440x900`。
- `workbench-map-b-minimal-mobile.png`：未连接态，`390x844`。
- `workbench-desk-b.png`：已连接态，`1440x900`。
- `workbench-desk-b-mobile.png`：已连接态，`390x1355`。

HTML/CSS 源稿用于读取几何关系，产品代码不得直接复制其示例业务内容。

## 未连接态：极简知识脉络

### 视觉优先级

1. “知序”是第一视口唯一品牌级标题。
2. 一句两行价值文案建立产品含义。
3. 蓝色主按钮完成唯一主任务“连接知识目录”。
4. 四节点关系图是主视觉，不是功能说明图或用户数据预览。

### 桌面几何

- 设计基准为 `1440x900`；图标轨 `78px`，Topbar `66px`。
- 主文案位于内容画布左上留白区，距画布左侧约 `74px`、距 Topbar 下方约 `90px`。
- 品牌标题约 `78px/1`，价值标题约 `30px/1.34`，正文约 `13px/1.8`；主按钮高 `44px`、圆角 `5px`。
- 关系图覆盖整个剩余画布，主线从左下向右上经过四个尺度不同的节点；只使用一条 `2.2px` 蓝色主线和一条 `1.1px` 冷灰提示线。
- 节点无卡片、无图例、无均匀网格。终点“待审提案”是唯一实心大节点，其余节点使用描边圆环与蓝色核心。

### 移动几何

- 设计基准为 `390x844`；图标轨 `52px`，Topbar `58px`，可用画布宽 `338px`。
- 文案距画布左右 `22px`，品牌标题 `56px`，价值标题 `24px`；主操作保持首屏可见。
- 移动关系图不是桌面图裁切，而是独立 `338x335` 构图，从约 `420px` 处开始；四个标签均位于节点外侧且不互相遮挡。
- 图形可做一次性路径绘制与淡入，`prefers-reduced-motion` 下直接显示最终状态。

## 已连接态：安静的今日知识桌面

### 视觉优先级

1. 日期、Workspace 和页面标题建立当前上下文。
2. 横向 Focus Strip 只放“一件要处理的事”与一个主操作。
3. 下方左侧承接一条真实资料线索，右侧列出最近资料。
4. 底部状态只是一行脚注，不形成系统卡片。

### 桌面几何

- 设计基准为 `1440x900`；完整侧栏约 `216px`，Topbar `66px`，内容画布左右约 `50px`。
- 日期标题区采用 `164px / 1fr / auto` 三列，页面标题约 `38px`。
- Focus Strip 采用 `164px / minmax(0,1fr) / 188px` 三列，高约 `176px`；边界和蓝色定位线承担层级，不使用浮动卡片。
- 下方采用约 `1.35fr / .65fr` 双栏，只有列分隔线；标题、正文与列表共享稳定基线。
- 白色与冷灰占主面积，蓝色只用于主操作、链接、当前定位和主关系，琥珀只表示等待决定，绿色只表示可用。

### 移动几何

- 内容转为单列：日期与标题、Focus 标签、对象内容、全宽主按钮、资料线索、最近资料依次排列。
- Focus Strip 不缩成卡片；顶部蓝线和分隔线继续表达层级。
- 资料处理脉络从三列横线改成单列竖线，保持标签和状态可读。
- 移动长稿用于验证完整页面节奏；`390x844` 首屏只要求页面标题、Focus 内容和主操作可见。

## 产品实现中的真实性修正

效果稿是视觉规格，不是 API 规格。实现时必须做以下有意修正：

- “最近进入”改为“最近捕获”，因为 Source Version 没有访问历史。
- 大段资料摘要改为真实文件名、相对路径和捕获时间，因为列表接口没有正文或摘要。
- “来源已连接 / 主题已归并 / 等待审阅”改为安全、解析、索引三个真实状态，避免猜测跨资源关系。
- `PROPOSAL / SOURCE VERSION / FRIDAY` 等装饰性英文小标题改为简短中文。
- 不显示全局统计、请求 ID、版本、能力矩阵或“未交付能力”说明。
- Clearline 全局导航继续拥有路由和菜单；首页只增加明确的入口壳变体，不复制导航事实。

## 还原验收

- 未连接桌面：品牌、主 CTA 和四节点主线在 `1440x900` 第一视口完整可见。
- 未连接移动：`390x844` 无横向溢出，主 CTA 无需滚动即可发现，四个标签无遮挡。
- 已连接桌面：Focus Strip 是首要工作区域，下面为连续工作面，没有 KPI 卡片墙。
- 已连接移动：主操作在第一视口，资料区单列且文本不遮挡。
- 两种状态均使用同一白蓝 Token、固定字号、`letter-spacing: 0` 和清晰 Focus Ring。
- 浏览器截图需与四张源稿并排检查；重点比对构图、留白、线条、主操作和信息密度，而不是复制示例业务文案。
